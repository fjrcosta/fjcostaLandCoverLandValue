    Methodological note

    One scene, five analytical dimensions

    The default view assigns each 109.45 m TabPFN grid cell the nearest DINOv2–LoRA land-cover classification and adds the OpenStreetMap urban road hierarchy. Land cover, land value and transport can be combined freely. Selecting LUD or LVY switches to the mutually exclusive municipal land-economics view.

    Urban land coverDINOv2 ViT-L/14 with LoRA; 10 mutually exclusive categories and classification confidence.
    Urban land valueTabPFN v2, configuration 60; the median unit-value estimate is used directly in R$/m² for a 450 m² reference parcel.
    Urban transportation networkOpenStreetMap drive network classified as motorway, trunk, primary, secondary and residential; duplicate directed geometries are removed for rendering.
    Municipal land economicsLUD relates GVA:CS+I to developed urban extent; LVY is a territorial economic-output proxy relative to estimated aggregate developed-land value, not a financial return rate.
    Multimodal commute reachability (Londrina)One-hour outbound commute from a selected origin (Bertaud's travel-time budget) by walking, car or bus, computed in the browser on precomputed OSM and CMTU networks. Industrial land cover serves as a simplified employment proxy; congestion, timetables and night lines are not modelled.
    Spatial integrationNearest-neighbour association in a projected metric CRS, performed offline by the preprocessing script.
    RenderingMapLibre GL JS with selectable OpenFreeMap or Esri World Imagery basemaps and deck.gl GPU extrusion of the exact four-vertex patch polygons. Static hosting; no application server is required.
